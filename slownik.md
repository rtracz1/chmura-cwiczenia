# D2. Słownik odpowiedników usług chmurowych

**Autor:** Robert Tracz  
**Grupa:** 1 CIM1NP025CI

| Rodzaj usługi | AWS | Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Przechowywanie obiektów (plików) | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Relacyjne bazy danych | Amazon RDS | Azure SQL Database | Cloud SQL |
| Funkcje bezserwerowe (FaaS) | AWS Lambda | Azure Functions | Cloud Run functions |
| Zarządzane klastry Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

*Usługi w jednym wierszu pełnią podobne funkcje, ale mogą różnić się możliwościami i sposobem rozliczania.*
